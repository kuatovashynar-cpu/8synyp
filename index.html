Доп қайда түседі?

Лақтырылған доптың жолы — парабола, ал оның жерге түсетін нүктелері — квадрат теңдеудің түбірлері. Жүгірткілерді жылжытып, допты жіберіп көріңіз.

Теория

ax² + bx + c = 0 теңдеуінің шешімі дискриминантқа байланысты: D = b² − 4ac

D > 0

Екі түбір: парабола х осін екі нүктеде қияды.

D = 0

Бір түбір: парабола х осіне жанасады.

D < 0

Түбір жоқ: парабола х осіне жетпейді.

x = (−b ± √D) / 2a

Виет теоремасы: x₁ + x₂ = −b/a, x₁ · x₂ = c/a

Түбірді табудың жылдам тексерісі: оларды қосып, көбейтіп көріңіз.
